# خلاصة التحقق وقت التسليم
الإصدار: 1.0.0، 6 سبتمبر 2026.

اختبارات ملفات Apps Script الفعلية بمحاكاة Google: 59 نجحت، صفر فشل. النتائج التفصيلية في tests/results.json. تشمل تحقق الحقول والتوقيع والتاريخ والدور والإصدار، والتكرار والإلغاء والاستكمال وإعادة الجدولة والإيقاف والحصة ونتيجة البريد المجهولة وفشل الحفظ بعد قبول البريد.
اختبار إضافي قابل للتكرار: node tests/check-signature.cjs. يشغّل Python محليًا وينشئ توقيع نص عربي ثم يطابقه في Node. اجتاز الاختبار. يتطلب أمر python، أو تعيين PYTHON إلى اسم الأمر الصحيح، دون حزم إضافية.
أدوات Python: اجتازت py_compile وإنشاء مجلد أمثلة والتحقق المحلي دون إرسال. لا تحتاج npm install ولا pip install.
ملف Word: يحتوي كل سطر غير فارغ من ملفات تشغيل Apps Script وmanifest وأداتي Python، دون سطور مفقودة. حُوّل محليًا بواسطة LibreOffice إلى 54 صفحة لفحص التخطيط؛ لم تظهر محارف خارج حدود الصفحة الآمنة ولا صفحات شبه فارغة. قد يختلف عدد الصفحات قليلًا باختلاف Word والخطوط.

لم يُختبر: Google الحي، صلاحيات حساب المستخدم، نشر /exec الفعلي، المشغّل الزمني الحقيقي، وصول بريد حقيقي، واجهة المستخدم أو خادمها، ضغط شبكي حقيقي، WhatsApp، Calendar، نظام العيادة، مراجعة أمان إنتاجية أو امتثال قانوني.
بيئة التنفيذ المحلية لا تملك اتصالًا بالإنترنت. المصادر الرسمية روجعت ببحث منفصل. لا يُعد ذلك اختبار تكامل حي.
سجل LIVE_ACCEPTANCE_AR.md متروك «لم يختبر» عمدًا. املأه بنتائجك، وليس بنتائج المحاكاة المحلية.
