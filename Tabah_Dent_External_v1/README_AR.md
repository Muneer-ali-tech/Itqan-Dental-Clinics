# ابدأ هنا: نظام طابة دنت الخارجي التجريبي
هذه حزمة Google Apps Script + Sheets + Email، وليست شيفرة الطرف المرئي. افتح تقرير Word أو REPORT_AR.md للتعليمات الكاملة والأكواد والمصادر.

## التنفيذ المختصر بالترتيب
1. اقرأ حدود النسخة وبوابة القبول. بيانات وهمية فقط، ولا ضمان تشغيل حي قبل اختبار حساب Google.
2. أنشئ Spreadsheet خاصًا وافتح Apps Script من Extensions. انسخ ملفات apps-script الستة وmanifest.
3. شغّل setupDemo، وأكمل Script Properties: بريد اختبار مملوك، REPLY_TO، ومفتاحا INGEST_SECRET وADMIN_SECRET عشوائيان مختلفان. لا تستخدم المفاتيح الوهمية في tests.
4. ابدأ DEMO_MODE=true وDEMO_FAST=true وMAIL_MODE=DRY_RUN وPAUSED=true. شغّل preflight ثم installWorker.
5. انشر Web app ينفذ كمالك مع وصول Anyone إذا سمحت سياسة الحساب. اترك ملف الجدول Restricted. استخدم /exec وليس /dev.
6. ولّد أمثلة بـ tools/make_examples.py، واختبر حدث إنشاء ثم تكراره بـ tools/send_event.py. هذه الأداة لا تتصل إلا عند تمرير --send.
7. حدّث الجداول، ثم استأنف المعالجة من قائمة Tabah DEMO. وضع DRY_RUN لا يرسل بريدًا ولا يُعاد ما عالجه بعد تبديل الوضع.
8. أوقف الإرسال، وانتقل إلى EMAIL بعد إعداد عناوينك. استخدم طلبًا جديدًا واختبر وصول البريد ثم confirm ثم cancel قبل استحقاق REMINDER.
9. سلّم HANDOFF_VSCODE_AR.md للطرف المسؤول عن المُرسل. لا تضع أسرارًا في المتصفح، ولا تكتب مباشرة إلى Sheets.
10. املأ LIVE_ACCEPTANCE_AR.md، وسجّل البروفة وثبّت نسخة النشر قبل الاجتماع.

## فحوص محلية
node tests/run-tests.cjs
النتيجة المرفقة: 59/59 نجحت على ملفات .gs الفعلية، لكن خدمات Google والبريد محاكاة. أداة Python لا تتطلب أي مكتبة إضافية. لا تضف tests أو tools إلى Apps Script.

## تنبيهات لا تتجاوزها
PAUSED يوقف الإرسال لا استقبال الطلبات. SENT يعني قبول MailApp وليس وصول البريد. UNKNOWN لا يعاد تلقائيًا. الردود يراجعها مسؤول التجربة يدويًا. stop يحظر البريد عالميًا، فاجعله آخر سيناريو أو على عنوان ثانٍ تملكه. لا تضف WhatsApp أو Calendar قبيل العرض. أكواد هذا الإصدار ترفض الإنتاج عمدًا.
